# Linux Sistems Lab
A hands-on laboratory focused on Linux systems administration, networking, infrastructure and automation.

This repository documents the journey of building and managing a professional Linux laboratory through real-world projects, following engineering best practices and documenting every step of the learning process.
## Objectives

- Build a professional Linux systems laboratory from scratch.
- Understand Linux internals instead of memorizing commands.
- Learn through realistic infrastructure projects.
- Develop strong systems administration and networking skills.
- Document every project following professional engineering standards.
- Build a portfolio suitable for systems, infrastructure and DevOps roles.

> **From first principles to production-ready infrastructure.**

## Learning Philosophy

This laboratory is not based on isolated tutorials or disconnected exercises.

Every topic is introduced through a realistic engineering scenario, explored from first principles, implemented in a hands-on environment and finally documented following professional standards.

The goal is not simply to learn Linux commands, but to understand how Linux systems are designed, administered and maintained in real-world environments.
