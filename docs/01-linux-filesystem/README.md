# Project 01 — Linux Filesystem Anatomy

## Overview

Understanding the Linux filesystem is one of the first steps towards becoming a systems engineer.

Rather than memorizing directory names or Linux commands, this project focuses on building a mental model of how a Linux system is organized, why each directory exists and how the operating system separates users, software, configuration and runtime data.

All concepts were explored through direct interaction with a Linux server, using standard command-line tools and following a hands-on learning approach.

## Learning Objectives

By the end of this project I was able to:

- Understand the purpose of the main Linux filesystem directories.
- Navigate the filesystem confidently using the command line.
- Distinguish between user data, system configuration, shared software and runtime information.
- Explore Linux systems using fundamental inspection tools.
- Develop a conceptual understanding of the Linux Filesystem Hierarchy.

## Concepts Covered

- Linux Filesystem Hierarchy Standard (FHS)
- Root directory (`/`)
- Home directories
- System configuration
- Variable system data
- Shared software directories
- Device files
- Filesystem navigation
- File inspection tools
- Basic filesystem exploration

## Practical Exploration

This project consisted of exploring the Linux filesystem directly from an Ubuntu Server environment. The purpose of each major directory was investigated, including locations for user data, system configuration, shared software, runtime information and device files.

Several fundamental inspection tools were used to understand the operating system without modifying it, allowing the filesystem hierarchy to be explored from a systems administration perspective.

## Key Takeaways

- Linux organizes the operating system following a well-defined filesystem hierarchy.
- Different directories exist for different purposes, such as user data, system configuration and shared software.
- Understanding the filesystem is more valuable than memorizing directory names.
- Linux administration begins by understanding how the operating system is structured before attempting to modify it.
