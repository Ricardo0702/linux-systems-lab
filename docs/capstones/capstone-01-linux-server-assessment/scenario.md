# Scenario

You have recently joined the Linux Infrastructure team of a technology company.

A colleague has prepared a new Ubuntu Server virtual machine that will soon be used as the foundation for future infrastructure projects. Before the server can be approved for production use, your team leader has asked you to perform an initial technical assessment.

Your objective is not to modify the server unless it is strictly necessary. Instead, you must inspect its current state, verify that the operating system has been configured correctly and produce a technical assessment based on your findings.

During the assessment, you should investigate the following areas:

- Filesystem organization
- Local users and permissions
- Running processes and system services
- Installed software
- Network configuration and connectivity

Use the tools that you consider appropriate to gather information and support your conclusions.

At the end of the assessment, prepare a technical report summarizing the current state of the server and highlighting any relevant observations or recommendations.
